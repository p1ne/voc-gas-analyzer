# Домашняя система мониторинга качества воздуха

Устройство собирает показатели качества воздуха с двух цифровых датчиков летучих органических соединений (ЛОС, VOC) и данные о скорости ветра в точке измерения. Контроллер работает под управлением ESPHome и передаёт результаты в Home Assistant.

## Состав устройства

В основе проекта — WeMos D1 mini Pro на ESP8266. К нему подключены:

- ENS160 + AHT2x для оценки качества воздуха;
- SGP41 для расчёта индексов VOC и NOx;
- чашечный анемометр с аналоговым выходом 0–5 В.

ENS160 и SGP41 работают на общей шине I²C. Анемометр подключён к аналоговому входу контроллера.

Расположение элементов внутри: [`device.png`](schematic/device.png)

## Список деталей для сборки
- Контроллер Wemos D1 mini pro
- Датчик VOC SGP41
- Датчик VOC ENS160 + AHT2x
- Аналоговый анемометр с выходом 0-5В и кронштейн для его крепления
- Wi-Fi антенна с пигтейлом U.PX (опционально)
- Вентилятор-улитка 5015
- Плоский кабель питания USB-microUSB достаточной длины
- Распаечная коробка с класом влагозащищенности не ниже IP65 (рекомендуется OBO Bettermann)
- Кабельные вводы для наружных подключений (4 шт без Wi-Fi антенны и 5 шт с ней)
- Сантехнические прокладки 3/4" с выпуклой сеткой (2 шт)
- Толстая резина или ластик, пробойник для резины - для изготовления уплотнителя в месте ввода кабеля
  
## Подключение

Схема подключения: [`esp8266-gas-analyzer-schematic.png`](schematic/esp8266-gas-analyzer-schematic.png). Векторный исходник: [`esp8266-gas-analyzer-schematic.svg`](schematic/esp8266-gas-analyzer-schematic.svg).

| Wemos D1 mini Pro | ENS160 + AHT2x | SGP41 | Анемометр |
|---|---|---|---|
| D1 / GPIO5 | SCL | SCL | — |
| D2 / GPIO4 | SDA | SDA | — |
| 5V | VIN | VIN | — |
| GND | GND | GND | GND |
| A0 | — | — | VOUT |

Адрес ENS160 на шине I²C — `0x53`, адрес SGP41 — `0x59`. На модуле ENS160 выводы ADD, CS и INT не используются.

На плате ENS160 установлен дополнительный датчик AHT2x. В текущей конфигурации ESPHome он не задействован: температуру и влажность контроллер получает из Home Assistant.

Для подключения внешней Wi-Fi антенны на плате WeMos D1 mini pro следует перепаять SMD-перемычку с внутренней антенны на разъем для подключения внешней. Если станция находится в зоне уверенного Wi-Fi, то внешнюю антенну можно не ставить.

## Что попадает в Home Assistant

ENS160 публикует три показателя:

- eCO₂ — оценочную концентрацию углекислого газа;
- TVOC — суммарную концентрацию летучих органических соединений;
- AQI — индекс качества воздуха.

SGP41 рассчитывает индексы VOC и NOx. Датчик опрашивается раз в 60 секунд. Для итоговых сенсоров ESPHome усредняет пять последовательных значений и отправляет результат после накопления окна — примерно раз в пять минут.

Анемометр опрашивается каждые 10 секунд. Полученное с A0 значение умножается на коэффициент `14`. В Home Assistant передаются текущее значение скорости ветра и среднее по 30 измерениям, то есть примерно за пять минут.

## Компенсация газовых датчиков

Показания ENS160 и SGP41 зависят от температуры и влажности. Вместо отдельного локального датчика конфигурация использует сущности Home Assistant:

- `sensor.local_weather_temperature`;
- `sensor.local_weather_humidity`.

Эти значения передаются обоим газовым датчикам как данные для компенсации. Поэтому для корректной работы важно, чтобы погодные сущности были доступны и регулярно обновлялись. Стоит проэкспериментировать - в зависимости от внешних условий, коррекция алгоритмов по влажности и температуре может быть как полезной, так и не очень.


Home Assistant получает данные о качестве воздуха, индексах VOC и NOx, скорости ветра.
